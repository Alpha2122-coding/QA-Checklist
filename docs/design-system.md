# Design System

## Color palette
- `brand-500`: #2563eb
- `brand-700`: #1d4ed8
- `slate-950`: #020617
- `slate-900`: #0f172a
- `slate-100`: #f8fafc

## Typography
- Primary font: Inter, system UI
- Heading weight: 600
- Body weight: 400
- Base font size: 16px

## Spacing
- Compact: 0.75rem
- Standard: 1rem
- Comfortable: 1.5rem
- Spacious: 2rem

## Accessible components
- Forms use clear focus states and labels
- Buttons maintain minimum contrast ratios
- Inputs and cards use high contrast backgrounds
- Mobile-friendly controls and tap targets

## Motion
- Use subtle fade and slide transitions for page changes
- Avoid excessive motion on system preference reduction
