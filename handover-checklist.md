- [ ] Install repository dependencies with `npm install`
- [ ] Create `.env` files from examples and configure secrets
- [ ] Run Prisma migrations and seed the database
- [ ] Start local development with `npm run dev`
- [ ] Validate frontend at `http://localhost:5173`
- [ ] Validate backend health at `http://localhost:4000/api/health`
- [ ] Review `CHANGELOG.md` for major updates
- [ ] Confirm test coverage and CI workflow files
- [ ] Verify Docker compose environment works for local parity
